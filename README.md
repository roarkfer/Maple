# Maple v8 Offline

Versión estática y offline de Maple v8 para GitHub Pages.

- Sin Lovable.
- Sin TanStack Router / Start.
- Sin servidor SSR.
- Los datos siguen usando `localStorage` con la clave `kompakt-lists-v1`.
- PWA offline mediante `public/sw.js`.
- La página de exportación de libretas se conserva como `export.html`.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
